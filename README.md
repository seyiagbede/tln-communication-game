# TLN Communication Style Discovery

A mobile-friendly, eight-question communication preferences game for TLN Leadership Accelerator Module 2.

## Publish

In this repository, open **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, branch **main**, folder **/(root)**, and save.

Once published, the game URL should be:

https://seyiagbede.github.io/tln-communication-game/

Use that URL to make a QR code for the Zoom slide. Participants can play on their phones without accounts.

## Delivery

Allow about 3 minutes for gameplay and 2 minutes for discussion. Invite participants to share their result voluntarily in Zoom chat and connect it to audience adaptation.

## Important

The result is an **informal learning reflection**, not a validated DISC or personality assessment. No server, analytics, or personal-data collection is included. The game does not replace the formal portfolio workbook.
